# 正式科研模型仍需要的实验/计算输入

当前原型已有可验证来源的化学计量 Cu₂Te 代表结构，因此不是 `toy_not_scientific` 玩具结构；
但它仍不能代表尚未确定的 Cu₂₋ₓTe 实际背接触相。正式计算前至少需要：

1. XRD、SAED/HRTEM 或可靠文献确定 Cu₂₋ₓTe 的室温/退火后晶相、空间群和晶格参数。
2. 实验给出的 x 或 Cu:Te 比，用来建立有依据的 Cu 空位数量、位置和有序方式。
3. 界面取向关系、CdTe 终止面（Cd 或 Te）和 Cu–Te 首接触原子层信息。
4. 更大的表面匹配搜索目标：允许的最大失配、最大原子数和可用计算资源。
5. 是否研究带电缺陷、磁性/自旋、SOC、色散修正，以及相应的收敛目标。
6. 如果目标是背接触势垒，还需决定是否在后续阶段加入 Au 和计算功函数/能带偏移。
7. 集群的 CP2K 版本、基组/赝势数据路径、SLURM account、partition 和容器/module 命令。

在这些信息缺失时，T0/T1/T2 只能验证建模、输入生成和结果解析流程。
