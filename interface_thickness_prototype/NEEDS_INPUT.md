# 正式科研模型仍缺少的输入

当前 CdTe 与化学计量 Cu₂Te 都来自已记录的公开结构来源，因此不是凭记忆编造的玩具晶格；但它们仍只是用于验证管线的代表性原型。正式研究前至少需要：

1. 用 XRD、SAED/HRTEM 或可靠文献确认退火后 Cu₂₋ₓTe 的晶相、空间群和晶格参数。
2. 实验确定 x 或 Cu:Te 比，才能建立有依据的 Cu 空位；本轮仍暂设 x=0。
3. 确认 CdTe/Cu₂₋ₓTe 的取向关系、Cd/Te 终止及第一接触元素。
4. 给出可接受最大失配、模型原子数和计算资源，才能扩大界面匹配搜索。
5. 在正式比较能量前，定义守恒的化学势、表面能或界面能参考。
6. 提供生产环境的 CP2K 版本、数据文件路径和 SLURM account/partition/module 配置。

B0/H1/H2 已修正为完整 Cu₂Te c 重复单元，能够保持相同 Cu 顶部终止和相同 Cu 首接触层；这只消除了第一版厚度定义的混杂变量，并没有确认真实样品一定采用该相和该界面。
