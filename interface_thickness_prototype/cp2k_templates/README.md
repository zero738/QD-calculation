# CP2K template policy

Inputs are generated from validated coordinates by `scripts/generate_cp2k_inputs.py`.
Bulk smoke jobs use `PERIODIC XYZ`; slabs use `PERIODIC XY` in both `CELL` and
`POISSON` with the `ANALYTIC` solver.  The default is PBE/GTH with the official
`BASIS_MOLOPT` DZVP-MOLOPT-SR q11(Cu), q12(Cd), and q6(Te) aliases, Gamma-only
sampling, and Fermi-Dirac smearing.  Optional TZVP/UCL settings are intentionally
not generated by default.  None of these settings is a production convergence claim.
